Tips

🌤️
Weather Agent — good sources

Wikipedia climate pages work great (e.g. wikipedia.org/wiki/Climate_of_Vietnam). Also try timeanddate.com/weather and weather-atlas.com. Avoid AccuWeather, weather.com — they require JavaScript.

💱
Currency Agent — good sources

Wikipedia currency pages (e.g. wikipedia.org/wiki/Vietnamese_dong) and Investopedia articles work well. Avoid Bloomberg, Reuters, WSJ — they require JavaScript or a subscription.

⚠️
JavaScript-rendered sites

Many modern sites (AccuWeather, BBC Weather, weather.gov) load content via JavaScript, which the scraper can't read. If you get a "requires JavaScript" error, switch to a Wikipedia or static page.

⏱️
Ingestion takes time

Each page is scraped, chunked, and embedded locally by Ollama. A single page takes ~15–30 seconds. Depth=1 may take a few minutes. The button will re-enable when done.

🔄
Re-ingesting a URL

Safe to re-add the same URL — ChromaDB upserts existing chunks rather than duplicating them. ChromaDB data also persists across server restarts.
